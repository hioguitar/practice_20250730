# 森信建設 支援の再定義 交渉メモ (2026-07-28時点)

## このフォルダの目的

昨日(7/28)発生した上原氏の事件、営業に出るよう求められている話、決まり事を作らず曖昧にする会社方針、これらを踏まえて、日置が明日からどう振る舞えば会社の100億目標達成に貢献できるかを考える場所。

「そもそも支援に足る人物か」という、より大きな方向性の問い自体は `carrire/` で扱う。ここでは、今の状況を前提として、日々どう動くかの実務・戦術を扱う。

## 背景

- DX導入支援で参画。導入が落ち着き業務の棚卸しを社長と決めたが進まず、営業・現場監督業務を求められている。
- 人生目的:困っている人(信用に足ると思える人)を、自分のできることで支援する。労働代行ではなく支援であることが前提。
- 会社の価値観として見えてきたもの:売上至上主義、バックオフィス投資の軽視、就業規則10年未更新、雇用条件明示書未発行(仮のものしかない)、就業規則を社員から見えない場所に意図的に置く(盾にされたくないため)。
- 会長・専務は日置さんを「売上を上げないコスト(金食い虫)」と見ている可能性が高く、社長もその圧力の中にいる。

## 交渉ロジック(5段階)

1. そもそもの参画目的(業務の仕組み化)に立ち返る
2. 「現場を知る必要がある」という反論には同意する(否定しない)
3. 「現場理解」と「成果(売上)」を切り分ける。売上要求が出たら、なぜ必要か理由を聞く
4. 期間限定・成果物限定の代替案を提示する(現場同行は自分ではなく既存スタッフが担当、自分はリサーチ目的で限定的に同行)
5. 新しい「支援」の再定義として着地させる

### 想定される分岐

- ①目的確認 → A:合意 / B:目的の再定義を主張(→契約見直しの土俵へ) / C:矮小化(→数値化させる) / D:はぐらかす(→仕切り直し提案)
- ③理解 vs 成果 → A:同意 / B:譲らない(→理由を聞く→本音が出れば見せ方を提案、押し切られれば契約見直しへ) / C:感情的になる(→関係修復フレーズ)
- ④期間限定同行案 → A:受諾 / B:範囲拡大要求(→頻度は交渉、ノルマなしは死守) / C:常態化の気配(→見直し時期を先に設定)
- すべてのエスカレーション経路は「契約条件を先に固める」に収束する

## 契約条件チェックリストで確定した事項

- 契約形態:正社員(雇用契約)で合意済み
- 書面発行の依頼:7/29(水)朝一・対面で実施(テキストでは行わない)。仮の書面との比較チェック表を用意する
- 成果物の定義:こちらから提案する。「業務フロー図・マニュアル・工事カテゴリ別の業者リスト」など"仕組み化のアウトプット"として定義し、売上ではないと明示する
- 報酬:仮の書面から変更がある場合のみ、変更理由の明示を求める
- 就業規則閲覧:全社員が常時確認できる環境整備を要求(根拠:労基法106条。違反時は労基法120条により30万円以下の罰金、また周知されていない就業規則は労働者に対し効力を持たないとした最高裁判例=フジ興産事件がある)
- 依頼のトーン:社長個人を責めず「制度整備の一環」として位置づける
- 完了期限:お盆休み明け(目安8/18週)を提示
- 想定:雇用条件明示書は法定最低限の記載にとどまる可能性が高い(具体例を書くと「明示書に記載がないので対応しません」と主張する社員が出ることを社長が懸念しているため。就業規則に具体例を書かなかったのも同じ理由)。そのため実質的な合意(業務範囲・成果物の定義等)は確認メールの方で担保する2段構えにする。確認メールは「この内容で進めます、修正があれば教えてください」と明示的な返信を引き出す形にし、会社のメール環境だけでなく個人的にもスクリーンショット等で保管する

## ロープレで得た学び(①-Bの最難関パターン)

有効だった技:
- 社長自身の過去の発言を引用し、成果物を"マニュアル"に着地させる
- 現場同行は既存スタッフ(中島さん・高村さん)が新人のOJTを担当し、自分は限定的なリサーチ目的でのみ同行する、という線引きを明確に持つ
- 「マニュアル+業者リストがあれば、未経験者でも自分が売上を出すより速く売上を出せる」という、会社の土俵(売上至上主義)の言葉で語る論理
- 効果測定・PR素材化など、社長が会長・専務に見せられる"数字以外の成果"を提供する
- 罰金・信用失墜・SNS炎上リスクを「会社を守るため」という社長と共通の目的に接続する

注意点:
- 長い一人語りは避け、区切って相手の反応を見ながら話す
- 「私は違うと思う」など断定的な否定は避け、柔らかい言い回しにする
- 曖昧な代名詞・言い回し(「私も現場についていく」と誤解されうる表現)は、出た瞬間に即座に否定して具体化する

## 社長が折れない場合の段階的対応

1. その場で退かず、畳みかけず、懸念の実体(何が一番のご懸念か)を聞く
2. 要求を分割する:法定最低限の明示書 + 確認メールでの実質合意、という2段構えに切り替える
3. 最低ラインとして、確認メールへの明示的な返信は必ず取り付ける
4. 動きがなければ、自分の中で次のアクションの期限を決めておく(労基署への相談は関係修復不可能になり得る最終手段であり、現時点では検討しない)
5. それでも一切動かないなら、それ自体が「この会社が今後どこまで信頼に足るか」への回答であり、支援対象を続けるかどうかという、そもそもの問いに立ち返る材料とする

# 100億勉強会 ブートキャンプ(2026-07-17)気づきメモ

日置さんが参加したブートキャンプでの思考の流れ・他参加者の意見・Claudeとの壁打ちで出た気づきを記録。

## 1. 視座の違い

視座=どの立場・高さから物事を見ているか(視点=何を見るか、視野=どこまで見えるかとは別軸)。

- 社長の視座:「100億に行く」という数字と5〜10年スパンの全社最適
- 社員の視座:目の前の業務と今日明日の負荷
- 日置さんの視座:両者の"翻訳者"。経営の意図を現場が飲み込める形に変換し、現場の本音を経営に伝え返す

**視座を変えると問題自体が変わる。** 「会社が悪い」「上司が悪い」「社員が悪い」という結論は、視座が固定された状態で出てくる症状にすぎない。問題に直面したら、誰が悪いかを先に決めず、まず「上司はどう感じてる?会社は?業界は?社会は?」とインプットの粒度を広げてから診断する。

### 視座の粒度と時間軸
- 粒度軸:事業部/会社/業界/社会
- 時間軸:1〜2年/5年/10年
- 日置さんの自己診断:「会社×1〜2年」に偏っていた。もっと粒度・時間軸ともに上げる必要がある
- ヒント:情報摂取の世代差(年配は日経新聞、若手はNewsPicksのイメージ)を使い分けの参考にする

## 2. 良いNo.2とは

- 社長の足並みを予測し、指示が来る前に提案できること
- ただし予測が顔色伺いに堕ちると単なるイエスマンになる。社長の**判断基準そのもの**を内面化しているから予測できる、という順序が重要
- **いつでも社長に変われる状態になるのがNo.2。** 「自分が社長になったらどう経営するか」を常にシミュレーションし続ける
- 予測・提案はしても、最終判断は社長のものとして残す境界線が必要

### 自分が社長ならどう経営するか(日置さんの回答)
組織体系を作る(マネージャー・リーダー・プレーヤー)→権限委譲→各自が考えるようになる。最初はマネージャーにこまめに確認(リーダーはちゃんとやってるか、課題は何か、なぜそうなっているか)。リーダー・社員にも直接声をかけ「大丈夫、できる、マネージャーを信じて進もう」と伝える。

### 他の参加者の意見(自分が社長ならどうするか・1巡目)
- 新しい文化を作る。礼儀・規律を整え、人材育成をしながら文化をつくる
- やる/やらないを判断する。プロ人材を引っ張る。権限移譲
- 今の事業の整理整頓。パーパスを実行できる人・プロ人材の採用
- 組織の構築。ビジョンが浸透していないので端的なビジョンにする。ビジョンを意識して営業成績を上げたい

→ 5人の回答は「ビジョン層/文化層/人材層/判断・構造層」に分かれる。誰も同じ角度から入っていない=経営は複数レイヤーの同時並行。
→ 共通して抜けている視点:**既に権限を握っている人からどう手放させるか**という移行のきっかけ(IXホールディングスは赤福事件がきっかけだった)。

## 3. 逆算思考・限界の特定

会社の未来を考え、どこまでが限界かを見極め、その限界を超えるには何をすればいいかを将来から逆算してソリューション提案できる人材が求められる。

- 逆算の前に「限界」を正確に特定する必要がある(限界を見誤ると、正しく逆算しても間違った制約を攻略することになる)
- 限界の可視化=業務プロセスの言語化が前提(工程が見えない状態でDXツールを入れても、本当のボトルネックに当たっているか分からない)

## 4. 採用基準

- 社長個人への興味で採用すると、社長の成長についていけなくなるリスクがある
- 社長の成長・会社の成長・ビジョンについてこれる人を採用すべき
- 「俺が経営するならこうする」と考えられる人材をどれだけ抱えられるかが、これからの会社に求められる(=経営者的思考の母数。この母数が権限委譲が機能するかどうかを規定する)
- **優秀さよりも文化の違いのほうが、人材の良し悪しの差を分ける。** スキル・経験の優劣ではなく、評価してきた文化と本人が持ち込む文化が合っているかどうかが本質
- **XLOCAL坂本さんの面接哲学①**:「うちに入るかは別として、自分は何がしたいのか」を先に聞く。会社への興味を先に聞くと迎合した答えが返ってくるため、会社を主語から外して個人の欲求だけを取り出し、それが結果として会社とつながっている人は採用、そうでない人は不採用
- **XLOCAL坂本さんの面接哲学②**:「入社初日何をするか」も聞く。人生目的が今日明日レベルの具体行動まで解像度高く逆算できているかを確認する質問

## 5. 役員/No.2とそうでない人の違い(複数意見)

- 会社の人間かそうでないか
- オーナーシップを持っているか
- 経験の差(弊社的な基準)
- 意思決定できるかどうか、パーパスや売上に対する今の現在地を見ているか(世の中的な基準)
- **未来の順序**:自分の実現したい未来が会社のビジョンの先にある=役員/会社のビジョンの手前にある=役員じゃない
- そもそも個人として「どうしたいか」があるかどうかが土台

## 6. SHONAIグループのロードマップ:器→仲間→フェア→エンジン

- **器を作る**→**仲間を集める**→**フェアにする**→**エンジンにする**、という順序
- 「フェアにする」の意味:既存メンバーと新参メンバーとの**収入ギャップをフェアにすること**
- 弊社の現在地:器・仲間の途中(組織図v2、LINE WORKS基盤、森田さんの先行導入)。フェア(新しい役割・機能を旧来の評価軸でどう公平に処遇するか)にはまだ手をつけていない
- 上原専務が日置さんを「売上を立てない人間」と見ているのは、旧来の評価軸(現場で売上を立てることが正当な評価対象)に、DX・技術支援という新しい役割がまだ翻訳されていない状態と読める

## 7. 「100億」という数字の扱い方

- 100億にとらわれると、プレゼンがワクワクしなくなる
- **100億は目的ではなくイメージ。** ワクワクするビジョンがあって、実現したとき大体100億くらいある、という感覚が正しい順序
- ビジョンは「何がどうなったらいいのか」を言語化すること
- ステークホルダーも巻き込んで成功していくイメージができるとよい(上原専務・西田部門長が何に困っていて、それがどう解消された状態が成功か、まで描けているか)
- 会社のビジョンの先に自分の目的があるところが◎(5章の「未来の順序」の再確認)

## 8. 日置さんの人生目的:「困っている人をサポートする」

私が社長だったら、「困っている人をサポートする」を人生目的として動く。社長が企業文化に困っていたら「順調ですか」「どうしたいんですか」と壁打ち役を買って出る。建設業でも同じで、「修繕に困っている」「会社をたたもうと思うけどどうしたら」「新築を建てたいけどどうしよう」といった内容に手を差し伸べる。そういう「困っている人をサポートする会社」として経営していく。今もその流れは少なからずあるので、ここをキャッチアップして経営できる。ただし現状の暗黙ルールやこれまでの経緯がデータとして残っていないため、そのデータ収集から始まる。データを一から作ってもよい。

同じカテゴリで会社を広げるなら「●●分野で困っている人をサポートする」——「社長をサポートする」「従業員をサポートする」「家族をサポートする」「子供たちをサポートする」「高齢者をサポートする」「地域をサポートする」——そのすべてに事業を広げる。すべてはアンパンマンのパトロールのように「困っている人をサポートする」というパーパスのもとで経営する。これは自分の人生目的とも、過去の成功体験とも、腹の底で感じていることにも全部リンクする。

### 今後の課題(解像度を上げる)
- どんな分野で売上を挙げていくのか
- 社会貢献・地域貢献はどの分野か
- 建設業でどこまで売上を挙げるか
- どれをどんな時間軸で行うか

→ 上記を言語化してビジョンとして組み立てたい(日置さん、2026-07-17時点でのメモ)。現在地(会社×1〜2年に偏っていた自己診断)を踏まえると、まず森信建設の中の「誰の・どんな困りごと」に絞って実績を作り、そこから同心円状に広げる順番が3章の逆算思考ともかみ合う。

## 9. XLOCAL坂本さんの言葉(まとめ)

- **エゴを外す話**:エゴを外して会社にとって優先度の高いことを選択したら、結果的に他の人のタスクを取ることになっていた。エゴを外したかどうかは本人の内面の話でしかなく、タスクを取られた側の視座では「境界を侵された」としか見えない。相手の視座から何を失ったように見えるかまで想像して手当てする必要がある
- **逆算のメッセージ**:一旦高い視座からの逆算をして、日々の課題に取り組んでほしい。視座を上げっぱなしで終わらせず、上げた視座から見えた本当の限界を、また普段の業務レベルまで戻して手を動かす往復運動が求められる
- **比率の話(オセロ理論)**:意思の高い人を1人入れただけでは、周りの文化に染まる(オセロのように多数側の色にひっくり返される)。だから採用はリソースを集中させ、一定の比率を確保する必要がある。そこで初めて新しい文化が生まれる。**ビジョンは多数決だ**
- 面接哲学の2つ(何がしたいか/入社初日何する)は4章に整理済み
- **締めの言葉**:とはいえ経営は楽しいものだ。みんな楽しくやっていこう!

## 10. その他の気づき
