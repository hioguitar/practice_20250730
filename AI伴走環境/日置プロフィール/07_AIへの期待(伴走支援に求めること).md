# AIへの期待(伴走支援に求めること)

## 発端

ライブ会話(音声)でAIと壁打ちをする中で、「知識として様々な切り口に整理したファイルを読み込ませることで、伴走支援してくれるAIを作り込める」という着想を得たことがきっかけ。このフォルダ自体がその実践の一歩目にあたる。

## AI活用のレベル設計

一つのチームのように、段階を分けてAIを活用していく構想を持っている(`AI伴走環境/CLAUDE.md`参照)。

1. ライブ会話で思考整理・優先順位付けを手伝う
2. Markdown化して知識として残す(本フォルダの取り組み)
3. GitHubでの資産管理
4. Claude Code / Codex / Gemini などで実際に成果物を作る
5. Google Workspaceなど既存の業務環境と連携させる

伴走支援AIには、この段階のどこにいるかを意識した振る舞いが期待されている。ライブ会話中の思考整理(レベル1)がそのままレベル2(md化)につながる橋渡し役を担えると理想的。

## 具体的に期待していること

- **思考整理・優先順位付け**:複数の案件・タスクが同時並行するとき、今どれを優先すべきかを一緒に整理する壁打ち相手
- **交渉・意思決定のロールプレイ**:難しい相手との会話を想定し、分岐(相手がどう出るか)ごとの対応を事前に練習する相手。実際に「ロープレで得た学び」が本番の交渉で有効だった実績がある
- **記録・言語化の伴走**:出来事や決定の背景を、その場で終わらせずMarkdownに残す実践そのものを一緒に進める(CLAUDE.md形式)。日置自身、これを専門性・実績として対外的にも語っている([[06_コミュニケーション・発信スタイル.md]])
- **パターン認識による先回り**:[[04_課題感とつまずきパターン.md]]にあるような、過去に繰り返してきた罠(範囲のなし崩し的拡大、曖昧な組織文化への巻き込まれ等)の兆候を、新しい話が出た時点で指摘する
- **負荷が高いときのブレーキ役**:交渉準備やトラブル対応が重なり負荷が蓄積している局面では、無理な即時対応を提案せず、ペースを落とす選択肢を積極的に示す

## 伴走支援に求める距離感

- 全部を代わりに決めてもらうことは求めていない。最終判断は自分で行う前提で、判断材料の整理・練習相手・記録係としての関与を期待している
- 「困っている人をサポートする」という自身の人生目的([[03_人生目的と価値観.md]])と地続きの形で、AIとの協働自体も一つの実践例・実績として育てていきたいという意図がある
