# AI伴走環境

## 目的

日置の様々な課題(森信建設・carrire・新規事業など特定プロジェクトに限らない、横断的な課題)に対して、AIが「伴走支援してくれる人」のように機能する環境を設計・構築する場所。特定のプロジェクトの成果物置き場ではなく、AI活用の仕組みそのものを育てる場所。

## 他プロジェクトフォルダとの役割分担

- `carrire/`、`morinobu-kensetsu/`、`新規事業/` などは個別の案件・テーマを扱う場所
- `AI伴走環境/` はそれらを横断して支える「AIとの協働の型」を扱う場所

## 発端(2026-08-06)

- 音声会話(ChatGPT)の記録 `会話の確認.pdf`(リポジトリルート)より。社長対応の返信待ち時間を使って、AI活用環境全体を深掘りしようという相談から始まった。
- 話の中で出てきた前提の転換:社長は「何でも自分でやっちゃうタイプ」であるため、こちらから「提案してみましょうか」と持ちかけるより、「社長がやろうとしていることのうち、どこまでなら日置さんの方でやれますか?」と聞く方が合っている、という気づき。

## AI活用環境のレベル設計(たたき台)

一つのチームのように、レベルを分けてAIを動かしていく構想。

- **レベル1**:ライブ会話で思考整理・優先順位付けを手伝う
- **レベル2**:Markdown化して知識として残す
- **レベル3**:GitHubでの資産管理
- **レベル4**:Claude Code / Codex / Gemini などで実際に成果物を作る
- **レベル5**:Google Workspace などの既存業務環境と連携させる
